# 06: 出镜视频入库：一条入库路径，CLI 也有入口

**What to build:** 把“接收出镜视频”做成 cc-core 的一个入库 operation：校验类型与存在性、复制到项目、并使旧抠像记录/产物失效。CLI 新增对应命令；MCP 的 person_matte(video_path) 与 app 的上传动作都调用它；MCP 的路径逃逸校验留在 MCP seam。用户可观察：三个壳对同一段视频执行相同的入库规则，AI 也能自助换片子。

**Blocked by:** 01, 05

**Status:** done

- [x] CLI/MCP/app 用同一套扩展名/存在性规则入库；CLI 有端到端入口。
- [x] 替换视频会清掉旧抠像记录与旧 alpha；随后抠像失败只能走卡片兜底，绝不复用旧人物。
- [x] MCP 的路径逃逸拒绝仍发生在 MCP seam；绝对路径沿用现有语义。
- [x] 测试覆盖支持格式、不支持格式、文件不存在、替换失效、CLI 端到端。
- [x] app 与 MCP 不再各自保留一份“复制 + 清旧抠像”的逻辑。
