# 02: Step6 版式预览与自由数值调整

**What to build:** 第 6 步的版式区显示真实第一页课件和人像/卡片预览；用户通过 X/Y/宽度滑杆或数字输入自由调整位置和大小，预览即时变化。形状和翻页动效仍可选择；调整保存后提示只需重渲成片，重新进入项目能恢复。

预览是前端实时叠加，不等待后端渲染；几何计算必须与 render 使用同一套归一化自由空间规则。人像优先使用已生成的抠像预览，跳过抠像时显示卡片兜底外观；课件区域保持 16:9 画布和白底留边，与成片一致。
