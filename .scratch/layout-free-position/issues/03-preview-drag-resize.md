# 03: 预览内拖拽与缩放

**What to build:** 用户可以直接在 Step6 预览里拖动人像到任意位置，拖角调整大小；拖动时实时预览，松手保存。提供恢复默认和四角/中心快捷位置，边界自动钳制，不再依赖输入框。

人像保持原始宽高比；缩放限制在宽度 5–40%，位置限制在自由空间 0–100，任何操作都不能让人像跑出画布。拖拽和缩放只响应对应画布区域，不误触“开始生成”等按钮。

## Comments

预览支持人像拖拽、右下角缩放手柄、快捷位置（左上/右上/左下/右下/居中）与
“恢复默认”（恢复旧 bottom_right/20%/圆角/硬切）；松手才写 layout.toml。拖拽与缩放
坐标按项目像素换算，宽度钳制 5–40%，高度超出画布时自动缩小，人像保持宽高比。
浏览器走查：拖动后 X/Y 滑杆更新、缩放后宽度从 20 到 30.5 且预览同步。自由 alpha/card
的 640x360 像素测试覆盖 render 几何与超高素材封顶；另外用真实 2 页项目分别在
1280x720 / 1920x1080 渲染自由位置成片，帧像素确认卡片位于预期位置。
